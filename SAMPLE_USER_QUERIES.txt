12. WHAT TO VERIFY ON EVERY ANSWER
================================================================================
  [ ] The IDENTIFIER column shows a business label ("i) Current",
      "ii) Overdue [ii.a + ii.b]"), NEVER a repeated date like
      "2025-03-31 00:00:00"
  [ ] The chart x-axis matches those labels and they are not all identical
  [ ] The "Understood as" chips describe the question you typed, and name a
      metric in business language ("Total Loan Assets"), not a column
      identifier ("TOTAL_LOAN_ASSETS")
  [ ] The Period chip shows the RESOLVED date and count
      ("31-MAR-2025 + 2 prior"), not the raw phrase you typed
  [ ] If you named a return, the answer came from that return
  [ ] Typing a NEW question clears the previous table and chart BEFORE it runs
  [ ] Running a manual Compute clears the stale "Understood as" chips
  [ ] 0.00% on every row is usually identical data, not a bug — 31-MAR-2025 and
      31-DEC-2024 on cims_raq_q_sec1_part_a_dom are genuinely identical in this
      database. Confirm in the DB before filing.

13. MANUAL SECTION — works for ALL returns, not just the 3 indexed ones
================================================================================
See SAMPLE_NLP_QUERIES.txt section 9 for the full manual checklist. The
essentials:

  Return search   : "cims raq", "cims ror", "cims nrd-csr", "rca3"
  Dates           : tick ONE date -> Periods chips (1/2/3) stay visible
                    tick TWO or THREE -> Periods disappears; ticked dates ARE
                    the periods, newest treated as current
                    a fourth tick is blocked (max 3)
  Non-consecutive : on 2041 tick 31-MAR-2025 + 30-NOV-2024 + 31-MAR-2023
  Columns         : "Columns n/n" menu; untick a value column and an info
                    column; hover a header for the x; hide-all shows a message
  Chart follows   : hide the charted column -> dropdown drops it, chart falls
                    back to the first visible one
